# 负荷特性预测完整交付包

## 1. 项目用途与范围

本交付包用于复现山东省负荷特性预测的完整计算链路，覆盖：

1. 读取 1996-2025 年宏观特征和全社会用电量，采用 ARIMA 外推产业增加值、人口等特征，再采用 MLP 映射得到 2026-2030 年电量预测。
2. 基于历史温度和负荷曲线计算基温、CDD/HDD 温度弹性，并生成 2030 年高温、正常、低温气候情景。
3. 使用历史行业曲线和用户级曲线，按周、日、小时三个层次生成目标年 8760 点标幺曲线。
4. 按目标年电量将行业标幺曲线定标为 MW 有名值，并可扣除重点行业得到剩余负荷。
5. 包含充换电和数据中心扩展链路，支持原始数据重建、训练预测、逐点比对和恒等式校验。

本包不包含 PPT 制作逻辑，不把人工排版作为模型步骤；不复制、不覆盖原始数据和原始结果。Word 手册保留在包内，作为补充的详细使用说明。

## 2. 目录结构和文件职责

```text
01_电量预测/       ARIMA 特征外推、MLP 电量预测和审计表
02_气温敏感性/     基温识别、CDD/HDD 弹性和 2030 温度情景
03_8760曲线/       用户合成、周日小时生成、标幺转 MW、剩余负荷
04_结果分析/       相关性、月度特性、温度敏感性分析
05_扩展行业/       充换电、数据中心原始代码和参数化复跑入口
负荷特性预测完整交付手册_20261013.docx  详细 Word 手册
requirements.txt   Python 依赖参考
run_delivery.ps1   交付版快捷运行脚本
```

主要脚本职责：`01_电量预测/forecast_arima_ml.py` 是主电量预测；`02_气温敏感性/build_base_kink.py`、`build_temperature_elasticity.py`、`build_temperature_years.py` 依次完成基温、弹性和情景；`03_8760曲线` 下脚本完成行业标幺曲线生成、定标和剩余负荷；`05_扩展行业/check_environment.py` 检查环境，`run_original_extensions.py` 完成扩展行业复跑及校验。

## 3. 输入数据

默认输入来自原工程的 `自己处理/存档/03_数据`，交付包不复制原始数据：

| 输入 | 默认相对路径 | 用途 | 关键格式 |
|---|---|---|---|
| `111.xlsx` | `02_统计与电量锚点/111.xlsx` | ARIMA 特征外推、MLP 电量预测 | 年份、三次产业增加值、人口、电力消费量、居民收入 |
| 山东全社会用电分类表 | `02_统计与电量锚点/山东2020-2025_全社会用电分类表（全口径）.xlsx` | 行业电量和 2030 定标 | 行业名称、年度电量 |
| 行业小时曲线 | `03_实测负荷8760/{年}` | 历史校验、行业曲线、扣除行业 | `时间,值`，每年 8760 点 |
| 用户级曲线 | `04_用户级负荷曲线/{年}` | 行业内用户归一化、等权融合 | 至少包含 `时间,值` |
| 数据中心原始 Excel | `05_数据中心原始` | 15 分钟聚合为数据中心小时 MW | `时间` 加测量点列，`-` 视为缺失 |
| 生成器输入 | `06_生成器输入目录` | 周/日/小时生成器 | 行业内含 `历史负荷数据2022.csv`、`历史负荷数据2023.csv` |

数据口径：小时功率为 MW；年电量为亿 kWh，换算关系为 `sum(MW) / 100000 = 亿 kWh`。标幺曲线只表达形状，通常按全年最大值归一化为 1，最后再按目标年电量恢复 MW。

已知数据事实：2022 年充换电曲线有 6168 个零小时，2023 年有 11 个零小时，复跑不会人为补齐；2023 年数据中心原始 Excel 有 275 个小时缺测，原始代码使用当月已有数据的逐小时典型值填充。

更换数据目录时，使用入口参数，不修改源脚本：

```powershell
& $python '05_扩展行业/run_original_extensions.py' `
  --hourly-root 'D:\数据副本\03_实测负荷8760' `
  --dc-raw-root 'D:\数据副本\05_数据中心原始' `
  --generator-root 'D:\数据副本\06_生成器输入目录' `
  --energy-xlsx 'D:\数据副本\02_统计与电量锚点\111.xlsx'
```

## 5. 推荐运行方式

### 5.1 扩展行业和主预测完整复跑

```powershell
& 'D:\App\Anaconda3\python.exe' '05_扩展行业\check_environment.py'
& 'D:\App\Anaconda3\python.exe' '05_扩展行业\run_original_extensions.py'
```

入口依次读取数据中心原始月度 Excel；删除玄铁站、含光站、飞天站，保留 16 站口径；将 15 分钟数据按小时取 4 点均值；与存档小时曲线比对；校验行业剩余负荷恒等式；生成充换电和数据中心 2030 标幺曲线；最后读取 `111.xlsx` 执行 ARIMA 特征外推、MLP 回测和 2026-2030 预测。

只复核扩展行业、不重复训练电量模型：

```powershell
& $python '05_扩展行业/run_original_extensions.py' --skip-arima
```

### 5.2 原始主链单独运行

推荐顺序为：`forecast_arima_ml.py` -> `build_nn_forecast_csv.py` -> `build_base_kink.py` -> `build_base_scan_fig.py` -> `build_temperature_elasticity.py` -> `build_temperature_years.py` -> `合成用户成行业标幺8760曲线.py` -> `批量生成2030行业8760标幺曲线_三假前当后周.py` -> `2030行业标幺曲线转有名值.py` -> `生成扣除重点行业剩余标幺曲线.py`。

原始整理脚本沿用历史目录约定，单独调用前需准备兼容目录，或在脚本开头调整 `DATA_ROOT`、`SRC`、`OUTROOT`。

## 6. 输出文件和验收规则

主要输出写入 `05_扩展行业/验证结果_原始数据`，不会覆盖原工程结果：

- `扩展行业与原始结果校验汇总.csv`：点数、时间连续性、缺失/零值、电量、逐点最大差、相关系数等。
- `数据中心重建/{年}/数据中心_MW.csv`：由 15 分钟 Excel 重建的小时曲线。
- `2030标幺8760曲线/{行业}_{训练口径}/2030年全年小时标幺曲线.csv`：充换电和数据中心预测曲线。
- `ARIMA预测2026-2030_原始数据.xlsx`：ARIMA 特征、MLP 回测、未来电量和模型说明。
- `主预测运行状态.json`：主预测成功或失败原因。

至少检查：2030 时间戳从 `2030-01-01 00:00` 到 `2030-12-31 23:00` 连续；曲线有 8760 行、无空值、无负值；标幺最大值为 1；有名值年电量满足 `sum(MW)/100000` 等于目标年电量；行业、数据中心和剩余负荷恒等式误差在容差内。

## 7. 已验证结果

- 数据中心 2022、2023 从 24 个原始 15 分钟 Excel 重建为 8760 小时；与存档曲线最大逐点差约 `0.0001 MW`，相关系数为 `1.0`。
- 2023 数据中心原始缺测 275 小时，按原代码典型小时填充。
- 八行业、数据中心、八行业剩余和九行业剩余恒等式通过，最大误差约 `1.5e-11 MW`。
- ARIMA+MLP 留出集为 2020-2025：4 特征 MLP 回测 MAPE `3.81%`，8 特征对照 MAPE `2.73%`；4 特征 2030 电量 `9180.0` 亿 kWh，8 特征对照 `10404.6` 亿 kWh。
- 充换电 2030 曲线已用原始周/日/小时生成器实际生成，同时输出 `2022+2023_hybrid`、`仅2023_hybrid`、`仅2023_pm1` 三种训练/节假日口径。

## 8. 复现边界和已知问题

历史充换电 2030 文件与当前生成结果没有逐点命中，最大差约 `0.77-0.79` 标幺，相关系数约 `0.66-0.75`。因此可以确认当前输入读取和训练运行正确，但不能宣称历史充换电结果被当前代码完全复现。若要完全复现，需要补齐存档脚本提到的 `20260910/_p15_work/输入/充换电服务业` 中间目录，并固定当时的生成器版本、节假日模式和参数。

充换电 2022 年大量零值属于原始数据覆盖事实，不是程序错误，也不会在复跑中自动平滑。历史 2030 文件是模型输出，不能与历史 MW 曲线直接逐点比较；应先统一训练口径和节假日规则，再比较形状，最后按同一年度电量定标。

原始脚本默认把历史数据根目录看作与算法目录平级的 `2026-08-12`，结果写入脚本附近的 `预测结果_2020-2030`。当前工作区输入分散在 `自己处理/存档/03_数据`，正式运行前需按输入表准备兼容目录，或通过扩展入口参数指定路径。
